# 🧾 My Todo List — Version 2.0

A clean and responsive task management web app built with **ReactJS**, featuring persistent local storage and an improved UI over v1.0.

---

## 🛠️ Tech Stack

- **ReactJS** — Component-based UI
- **CSS3** — Styling & responsive design
- **Local Storage** — Persistent data management

---

## ✨ Features

- **Add Tasks** — Quickly add new tasks via a simple input field
- **Delete Tasks** — Remove individual tasks to keep the list clean
- **Persistent Storage** — Tasks are saved in local storage and remain after page refresh
- **Responsive Design** — Works seamlessly on both desktop and mobile devices
